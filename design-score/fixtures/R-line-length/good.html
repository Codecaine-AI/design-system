Why the release checklist moved

The release checklist used to live in three places: the repo wiki, a pinned note and the deploy script's comments. Each copy drifted, and two releases went out with a step that one copy had dropped. One page in the docs hub now holds the list, and each repo links to it.

Read the checklist before you tag a release. Each step names the command to run and the result to check, so a missed step shows up before the deploy and not after it.
